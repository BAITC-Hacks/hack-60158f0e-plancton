# Классификатор обращений

Маленький скрипт: читает обращения из `messages.txt`, для каждого печатает
категорию (**справка / жалоба / другое**) и черновик ответа на русском.

## Как запустить

Нужен только Python 3.8+, зависимостей нет.

```bash
python3 classify.py               # берёт messages.txt из текущей папки
python3 classify.py other.txt     # другой файл: одно обращение на строку
```

Опционально — классификация одним вызовом LLM вместо правил:

```bash
pip install anthropic
export ANTHROPIC_API_KEY=...
python3 classify.py --llm
```

Если ключа/сети нет или модель вернула неожиданный формат, скрипт пишет
предупреждение и откатывается на правила — запуск не падает.

> Режим `--llm` проверен на заглушке вместо сети (сборка запроса и разбор
> ответа) и статически — параметр `output_config` есть в anthropic 1.7.0.
> Живого вызова к API не делали: ключа под рукой не было.

## Что получилось

На пяти тестовых обращениях разметка совпадает с ожидаемой:

| # | Обращение | Категория |
|---|-----------|-----------|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi-Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | другое |

Категория пятого обращения спорная: «справка» здесь понимается как документ,
поэтому вопрос о парковке отнесён к «другое». Если в команде принято считать
справкой любой справочный вопрос — правится одной строкой в `CERTIFICATE_PATTERNS`.

## Как устроено

- **Категория** — по ключевым словам (`classify.py`, списки `COMPLAINT_PATTERNS`
  и `CERTIFICATE_PATTERNS`). Считаем совпадения в каждой группе: есть маркеры
  жалобы — «жалоба», иначе есть маркеры документа — «справка», иначе «другое».
- **Ответ** — по паре «тема + категория» (`TOPICS`: справка о месте учёбы,
  питание, Wi-Fi, запись на консультацию, парковка). Тема даёт содержательный
  черновик, категория — тон: на «не выдают справку неделю» уходит ответ на
  жалобу, а не инструкция по заказу документа. Если для пары нет шаблона,
  берётся общий шаблон категории.

## Ограничения

- Правила покрывают типовые формулировки; сленг, опечатки и редкие темы
  разметятся хуже — для таких случаев и нужен режим `--llm`.
- Тема распознаётся узкими паттернами: «справка для бассейна» темой не
  считается и получает общий ответ с уточняющим вопросом. Это осознанно —
  лучше уточнить, чем выдать инструкцию не про тот документ.
- Черновики ответов содержат условные сроки и места (деканат, главный вход) —
  под реальные регламенты их надо поправить.
