# Классификатор обращений

Маленький скрипт: читает обращения из `messages.txt`, для каждого печатает
категорию (**справка / жалоба / другое**) и черновик ответа на русском.

## Как запустить

Нужен только Python 3.8+, зависимостей нет.

```bash
python3 classify.py               # берёт messages.txt из текущей папки
python3 classify.py other.txt     # другой файл: одно обращение на строку
```

Опционально — классификация одним вызовом LLM вместо правил:

```bash
pip install anthropic
export ANTHROPIC_API_KEY=...
python3 classify.py --llm
```

Если ключа/сети нет или модель вернула неожиданный формат, скрипт пишет
предупреждение и молча откатывается на правила — запуск не падает.

## Что получилось

На пяти тестовых обращениях разметка совпадает с ожидаемой:

| # | Обращение | Категория |
|---|-----------|-----------|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi-Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | другое |

## Как устроено

- **Категория** — по ключевым словам (`classify.py`, списки `COMPLAINT_PATTERNS`
  и `CERTIFICATE_PATTERNS`). Считаем совпадения в каждой группе: есть маркеры
  жалобы — «жалоба», иначе есть маркеры документа — «справка», иначе «другое».
- **Ответ** — отдельно от категории, по теме обращения (`TOPICS`: справка о
  месте учёбы, питание, Wi-Fi, запись на консультацию, парковка). Тема даёт
  содержательный черновик, а не отписку; если тема не распозналась,
  берётся общий шаблон для категории.

## Ограничения

- Правила покрывают типовые формулировки; сленг, опечатки и смешанные
  обращения («не дали справку уже неделю») разметятся хуже — для таких
  случаев и нужен режим `--llm`.
- Черновики ответов содержат условные сроки и места (деканат, главный вход) —
  под реальные регламенты их надо поправить.
